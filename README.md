# cloudesplan Hackathon - Ear of GTU (otonom feedback sistemi)

[Demo Videosu](Buraya video linkini ekle)

## Problem
Öğrenciler ile GTÜ arasındaki iletişimsizlik, Geribildirim vermenin çoğu kişiye zor gelmesi veya verilen geribildirimlerin uzun sürmesi, yada dikkate alınmaması.

## Çözüm
aradaki herhangi bir engeli ortadan kaldıran geribildirim iletmeyi ve almayı pürüssüzleştiren bir feedback sistemi.

## Çalıştırma Adımları **(önceden yazılı gerekirse değiştermyi unutma)**
Projeyi çalıştırmak için bilgisayarınızda Docker ve Docker Compose kurulu olmalıdır.
1. Depoyu klonlayın.
2. Terminalde proje kök dizininde `docker compose up --build` komutunu çalıştırın.
3. Ön yüz için `http://localhost:3000` adresine gidin.
4. Arka uç API için `http://localhost:8000` adresini kullanın.
